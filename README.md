# Operation-aware estimand alignment

Code and summary tables accompanying the revised MIA manuscript. The analysis compares pooled frame AUROC with equal-operation, within-operation AUROC on the locked Endoscapes test cohort. It also reports a label-free, operation-constant score shift as a sensitivity analysis. These are descriptive analyses, not estimates of deployment performance or causal effects.

## Data access

The Endoscapes2023 dataset is restricted-access on [PhysioNet](https://physionet.org/content/endoscapes-2023/1.0.0/) (DOI: [10.13026/czwq-jh81](https://doi.org/10.13026/czwq-jh81)). This public repository does **not** contain images, videos, frame-level labels or predictions, video/frame identifiers, or per-operation support tables. The frozen prediction files used for the reported results are also not generated by this repository. Consequently, the published summary tables can be checked against the scripts, but the study-level numbers cannot be independently regenerated from this repository alone. Authorized access to both the dataset and the frozen prediction files is required.

The withheld files follow the pattern `locked_test_predictions_seed{17,29,43}.csv`. Each has columns `video,frame,y_c1,y_c2,y_c3,p_c1,p_c2,p_c3`. Do not add them to a public fork or release unless redistribution permission is established separately.

## Run the code

Use Python 3.11 or later and install the dependencies with `python -m pip install -r requirements.txt`. Run the public tests with:

```bash
python test_oea.py
python test_extended.py
python test_reproduction.py
```

For an authorized local copy of the frozen predictions, run:

```bash
python verify_bootstrap.py --data-dir /path/to/predictions --out /path/to/output/pair_support.csv
python original_protocol/regenerate_10000_bootstrap.py --data-dir /path/to/predictions --out-dir /path/to/output
```

The bootstrap uses 10,000 paired operation-cluster draws and a fixed random seed. The outputs correspond to `EXACT_10000_CLUSTER_BOOTSTRAP.csv` and `EXACT_10000_JOINT_RANKING.csv`. The estimand definitions and exclusions are in `original_protocol/estimand_registry.json` and `original_protocol/analysis_protocol.json`. The scripts do not train the original models or recreate their frozen predictions.

`oea.py` can also audit a local prediction table directly:

```bash
python oea.py /path/to/predictions.csv --operation video --label y_c1 --score p_c1 --out /path/to/output/audit.json
```

## Scope of this release

The figures and aggregate tables document the reported analysis. Some frozen predictions were also used in another manuscript; these are shared derived assets, not an independent clinical cohort. The 6 October draft was superseded by the revised manuscript.

The MIT license covers the repository's original code and documentation. It does not grant permission to redistribute Endoscapes data or the withheld prediction files; the dataset's own access and use terms continue to apply.
